# Product

## Register

product

## Users

Admire company employees across multiple roles: owners, accountants, admin staff, factory leads, stock managers, and site team. They work in office and factory environments, primarily on desktops and tablets. Each role sees a permission-filtered subset of the platform and uses it mid-task — calculating a BOM during a client call, checking stock before a delivery, running payroll at month end.

## Product Purpose

Admire is an all-in-one operations platform for an LED signage manufacturing and installation company. Its core workflows: BOM calculation and quote generation for LED screens and flex signage boards, inventory and stock ledger management, CRM with quote linking, project BOQ tracking, structural material planning, 1D/2D cut-list optimization, attendance tracking, and payroll. Success looks like a team that can price a job, place an order, and track a project without leaving the app.

## Brand Personality

Precise, professional, trusted. The tool earns confidence through accuracy, not decoration. Voice is direct and factual. The interface should feel like it belongs in a workshop that takes its craft seriously.

## Anti-references

- Generic SaaS template aesthetic (Notion-style pale-gray + blue, Linear clones with oversized empty states)
- Consumer-app playfulness (bouncy animations, marketing gradients, card grids that look like an app store)
- Over-instrumented data dashboards that sacrifice clarity for completeness

## Design Principles

1. **Accuracy above all** — Every number carries real money and real decisions. The UI must make correct input easy and errors immediately visible. Ambiguous states are not acceptable.
2. **Role-appropriate surface** — Factory leads don't need CRM; site team doesn't need BOM settings. The interface should surface exactly what each role needs, nothing more.
3. **Consistency earns trust** — Same component vocabulary everywhere. If a save button looks different in two screens, one is wrong. Earned familiarity beats clever novelty.
4. **Speed, not spectacle** — Users are mid-task. No decorative delays, no orchestrated reveals. Motion communicates state, not personality.
5. **Print is a first-class feature** — Quotes and BOQs leave this app as printed client documents. Print layout is part of the product, not an afterthought.

## Accessibility & Inclusion

No specific WCAG level required beyond good defaults. Ensure sufficient color contrast for data-dense tables (body text ≥ 4.5:1). Dark mode support already in place. Reduced-motion support for any animations added.
